# 🏦 Intelligent Loan Approval & Credit Risk Prediction System

An intelligent loan approval and credit risk prediction system built with supervised learning.  
This project uses historical loan data, preprocessing pipelines, and machine learning models to predict loan approval status, probability scores, and applicant risk levels.

---

## ✨ Features
- Predict loan approval (Approved / Rejected)
- Show approval probability %
- Assess applicant risk level (Low / Medium / High)
- Interactive Streamlit frontend for user input
- Modular design with saved artifacts (`loan_model.pkl`, `scaler.pkl`, `encoder.pkl`, `feature_columns.pkl`)

---

## 🛠 Tech Stack
- **Python** (pandas, scikit‑learn, joblib)
- **Streamlit** (frontend UI)
- **Pickle/Joblib** (model persistence)
